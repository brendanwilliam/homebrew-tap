# Homebrew Tap

Official Homebrew casks for [Clive](https://github.com/brendanwilliam/clive).

```sh
brew install --cask brendanwilliam/tap/clive
```

Clive requires an Apple-silicon Mac running macOS 14 or later. Update with `brew upgrade --cask brendanwilliam/tap/clive`. Ordinary `brew uninstall --cask clive` preserves Clive pairing state; `brew uninstall --cask --zap clive` explicitly removes it.
